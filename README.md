# James Cantonwine

Director of Research & Assessment at [Peninsula School District](https://github.com/psd401) in Gig Harbor, Washington. Former physics and math teacher.

I build tools for problems I see in our district, mostly with AI-assisted development, and we open-source what we can.

## What I'm working on

- **[Secure Test](https://github.com/psd401/secure-test)**: macOS secure testing browser and teacher assessment design tool. In classroom pilots.
- **[LessonLens](https://github.com/psd401/lessonlens)**: privacy-first AI coaching for teachers. Transcription happens on the device, and administrators have no access to teachers' data.
- **[AI Studio](https://github.com/psd401/aistudio)**: self-hosted, multi-model AI platform for K-12 (contributor).
- **[PSD Claude plugins](https://github.com/psd401/psd-claude-plugins)**: the Claude Code workflows we use to build all of the above (contributor).

## How I work

Small PRs, written release ledgers, security scanning on every repo, and student data privacy (FERPA) treated as a design constraint rather than a review step.
